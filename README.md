# Tic Tac Toe

A command-line based Tic Tac Toe game for two players, built using 
Python and Object-Oriented Programming concepts.

## Features
- Two-player gameplay (X and O take turns)
- Win detection (checks all rows, columns, and diagonals)
- Draw detection when the board is full
- Input validation (handles invalid input and already-filled cells)

## Concepts Used
- Classes and Objects
- `self` and `__init__`
- Conditional logic for win-checking
- Exception handling (try-except for invalid input)

## How to Run
```bash
python tic_tac_toe.py
```

## What I Learned
This was my first project converting function-based code into 
Object-Oriented Programming — understanding how `self` works and 
how class attributes replace global variables.
